# Tarsima

**Find places that fit both of you.**

Tarsima is an agentic shared-taste discovery product built for the **Qloo Agentic Hackathon 2026**.

Two people each choose 3–5 things they like, add a destination city, and Tarsima finds a small set of places supported by shared Qloo evidence. Recommendation selection remains deterministic; the AI layer is limited to grounded explanation after the places have already been selected.

## How it works

The current submission flow is:

`Taste inputs + destination`
→ `Qloo entity resolution`
→ `server-side selection verification`
→ `request-local taste profiles`
→ `live Qloo place retrieval`
→ `deterministic reconciliation and ranking`
→ `bounded Gemini explanation`
→ `deterministic validation`
→ `Tarsima UI`

### Why Qloo is essential

Qloo is the source of cultural and place evidence used by the recommendation pipeline.

The final venue set is not generated by an LLM. Qloo-backed candidates are reconciled by deterministic application code, including intersection, ranking, category fallback, and deduplication.

### Agent authority boundary

The Gemini-backed agent may explain already-selected recommendations.

It may not:

- invent venues;
- substitute a selected venue;
- reorder deterministic results;
- bypass evidence validation; or
- change recommendation policy.

Deterministic validation remains the final authority before results are presented.

## Current submission surface

The deployed experience supports:

- destination city input;
- 3–5 explicit Qloo-resolved taste seeds per person;
- two-person shared-taste discovery;
- live Qloo retrieval;
- deterministic shared-place selection;
- bounded Gemini explanations with deterministic fallback;
- English presentation;
- Arabic presentation with RTL layout;
- responsive mobile UI.

## Local setup

Requirements:

- Node.js `>=22.6.0`
- npm
- Qloo API key
- Google Gemini API key

Install dependencies:

    npm install

Create the local environment file:

    Copy-Item .env.example .env.local

Set these values inside `.env.local`:

    QLOO_API_KEY=
    GEMINI_API_KEY=

Never commit real secret values.

Run the development server:

    npm run dev

Open:

    http://localhost:3000/en

or:

    http://localhost:3000/ar

- `.env.example` contains names only.
- Production secrets are configured through the deployment provider.
- Client input does not acquire recommendation authority.
